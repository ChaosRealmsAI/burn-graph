# M01 — AI can converge and observe local prompt graphs

Target version: `0.1.0-dev.1`.

The user can initialize one project, have AI actors drive multiple persistent
graphs through a stable CLI, and watch truthful Mermaid state in a local
browser.

Exit Gates:

- UP01, UP02, UP03, and UP04 pass from their real entries.
- A known-bad topology and known-bad duplicate claim make their Gates fail.
- Build, typecheck, unit, integration, CLI E2E, restart, concurrency, an
  isolated dependency-free package install, and a lightweight read-only Viewer
  smoke pass.
- The remaining implementation after bootstrap is recorded by burn-graph's own
  self-hosted graphs.
